# Q-Limit 📈

**Q-Limit** is a modern, efficient open-source stock market analysis and AI multi-role assisted decision-making system. It integrates real-time market tracking, full-dimensional technical/financial/valuation analysis, and a distinctive **Multi-Camp AI Debate** feature, dedicated to providing investors with an objective and in-depth market analysis tool.

> 🤖 **About this project:** The frontend rendering, backend architecture design, and all API integrations of this project were collaboratively developed and generated by AI under the user's natural language guidance. This is not only a practical stock analysis platform but also a Proof of Concept (PoC) for the implementation of Agentic AI in a complex full-stack financial project.

> ⚠️ **Note on Language:** Currently, the system UI and data sources (news, technical analysis descriptions) are primarily in **Chinese**. Full internationalization (i18n) is planned for future releases. Contributions and PRs for multi-language support are highly welcome!

## ✨ Core Features

- **🌍 Pure Frontend LLM Proxy Access**: Supports native access for chat-only LLMs. Without needing complex Function Calling support, the system automatically performs **Context Injection**. It queries the latest stock trends, technical indicators, and news in the background and feeds them to the AI, instantly giving your chatbot real-world financial analysis capabilities!
- **⚔️ Pioneering AI Long/Short Debate Arena**:
  - 🐂 **Bull Analyst**: Focuses on uncovering various potential positive factors and upward trends.
  - 🐻 **Bear Analyst**: Acts as the Sword of Damocles, responsible for warning about valuation bubbles and uncovering hidden risks.
  - ⚖️ **Judge**: Conducts an objective review based on the arguments of both the bull and bear sides, ultimately providing realistic and actionable trading advice.
- **📊 Full-Dimensional Dashboard**:
  - K-line charts (daily and minute charts combined with technical indicators).
  - Panel integration: ticker tape quotes, valuation analysis, technical pattern monitoring, and trending news.
- **🔎 Tavily Web Search Component**: Supports external web search via Tavily to enrich AI analysis context.
- **🔔 DingTalk Notification Component**: Supports pushing key analysis outputs (such as judge conclusions) to a DingTalk bot.
- **⚙️ Dual AI Configuration Paths**: You can define default AI model settings in backend `.env`, and still override them per browser in the settings panel when needed.

## 🚀 Quick Start

The backend of this project is built with lightweight **Python Flask**, with simple dependencies and extremely fast startup.

### 1. Prerequisites

Please ensure your system has installed:
- Python 3.8+
- SQLite (Python built-in `sqlite3`, no external DB service required)

### 2. Get the Code & Install Dependencies

```bash
git clone https://github.com/zhaoboy9692/Q-Limit.git
cd Q-Limit

# It is recommended to use a virtual environment
python3 -m venv venv
source venv/bin/activate  # Windows users use `venv\Scripts\activate`

# Install dependencies
pip install -r requirements.txt

# Initialize env file (Tavily/DingTalk settings)
cp .env.example .env
```

### 3. Configure Database & Start

The project uses SQLite as a local cache (K-lines, news, chat history, etc.), so no separate DB service is required.
You can configure the DB file path with `SQLITE_DB_PATH` in `config.py` (default: `data/stock_analysis.db`).

**Start the backend server:**
```bash
python3 app.py
```
> The server will start at `http://127.0.0.1:5000` .

### 4. Configure AI Models

Recommended: edit `.env` first:
- `AI_DEFAULT_API_KEY` / `AI_DEFAULT_BASE_URL` / `AI_DEFAULT_MODEL`: global default model config
- `AI_BULL_*` / `AI_BEAR_*` / `AI_JUDGE_*`: per-role overrides for bull, bear, and judge
- `AI_REQUEST_TIMEOUT_SECONDS`: AI request timeout

After the system starts, visit `http://127.0.0.1:5000` in your browser. You can still use the **"⚙️ Settings"** panel to override config locally for the current browser. Values entered in the frontend take precedence; blank fields fall back to `.env`. Supports any endpoint compatible with the OpenAI `/v1/chat/completions` format.

### 5. Configure Tavily and DingTalk (Optional)

Edit `.env`:
- `TAVILY_API_KEY`: Tavily API key
- `TAVILY_SEARCH_DEPTH`: `basic` / `advanced`
- `TAVILY_TIME_RANGE`: default time window such as `day/week/month/year`
- `TAVILY_INCLUDE_DOMAINS` / `TAVILY_EXCLUDE_DOMAINS`: comma-separated domain allow/block list
- `TAVILY_INCLUDE_ANSWER` / `TAVILY_INCLUDE_RAW_CONTENT`: whether to return Tavily summary and source snippets
- `TAVILY_CACHE_EXPIRE`: SQLite cache TTL in seconds to avoid burning Tavily quota repeatedly
- `DINGTALK_ENABLED`: enable DingTalk notifications (`true/false`)
- `DINGTALK_WEBHOOK`: DingTalk bot webhook
- `DINGTALK_SECRET`: DingTalk signing secret (if enabled)
- `DINGTALK_NOTIFY_ON_DEBATE`: auto-send judge result after debate
- `DINGTALK_STREAM_ENABLED`: enable DingTalk app bot Stream receiver
- `DINGTALK_CLIENT_ID`: app `AppKey`
- `DINGTALK_CLIENT_SECRET`: app `AppSecret`
- `DINGTALK_AGENT_ID`: app `AgentId`

When the DingTalk bot receives `#command`, it will execute rules from [`Bot_Skills.txt`](Bot_Skills.txt), e.g.:
- `#PRICE 601988`
- `#NEWS AAPL`
- `#ANALYZE BABA`
- `#CONFIG 长桥` (Longbridge) / `#CONFIG 老虎` (Tiger): in a private chat, reply with the official OpenAPI developer credentials step by step (Longbridge: App Key / App Secret / Access Token; Tiger: tiger_id / account / RSA private key). The bot performs a real login and only saves on success
- `#ACCOUNT` shows assets and positions of the logged-in broker; `#BUY` / `#SELL` still never place real orders
- `#CONFIG 查看` checks current config, `#CONFIG 删除` removes it, and `#q` or `#CANCEL` aborts the active flow
- `#CONFIG 同花顺`: mainland A-share brokers are reached through a small read-only bridge running next to the broker's THS trading client on a Windows machine in your LAN; see [`tools/ths_bridge/README.md`](tools/ths_bridge/README.md)
- Futu and IBKR need a local gateway and are not supported; credentials are stored in plain text in the SQLite database, so only run this on a machine you control
- The Longbridge SDK's prebuilt Linux wheels need glibc ≥ 2.39 (the Docker image satisfies this); other features keep working if it cannot be installed
- The login flow auto-exits after 60 seconds of inactivity

`/api/search/web` now supports richer Tavily options, for example:
- `topic=finance`
- `time_range=month`
- `days=7`
- `include_domains=sec.gov,investor.apple.com`
- `include_raw_content=text`

### 6. Docker Deployment (Optional)

```bash
docker compose up -d --build
```

Or skip the local build and use the image published to GHCR by GitHub Actions (amd64 / arm64):

```bash
QLIMIT_IMAGE=ghcr.io/summerxdsss/q-limit:latest docker compose up -d --no-build
```

Open `http://127.0.0.1:5000` and fill in the AI / Tavily / DingTalk settings under **"⚙️ Settings → 🛠 服务端配置"** — no hand-written `.env` needed.

- The SQLite database and `.env` live in the `qlimit-data` volume (`/app/data` in the container) and survive rebuilds.
- The port is bound to the host's `127.0.0.1` by default. Change it with `QLIMIT_PORT=5050 docker compose up -d` if 5000 is taken (e.g. by the macOS AirPlay Receiver).
- To expose it on your LAN use `QLIMIT_BIND=0.0.0.0 SETTINGS_ALLOW_REMOTE=false docker compose up -d`. The in-page server settings are then disabled so others cannot change your keys or endpoints; edit `/app/data/.env` in the volume instead.
- The container runs gunicorn with a single worker and multiple threads (the DingTalk Stream bot and live config reload are in-process state, so do not add workers).

## 🛠 Technical Architecture

- **Backend Layer**: Flask + Requests + SQLite. Primarily responsible for receiving frontend data, querying data through various aggregated market APIs, assembling it, and forwarding SSE streaming requests to third-party AIs.
- **Data Layer**: Uses SQLite for lightweight local caching and persistence of historical analysis data.
- **Frontend Layer**: Vanilla JS + CSS variable customization system + ECharts K-line rendering engine. Full Single Page Application (SPA) interactive experience, with a modern UI and elegant built-in Dark Mode.

## 📖 Usage Guide

- **Search & Watchlist**: Type the stock code (e.g., `AAPL`) in the top search box to get it directly. You can also add it to the Watchlist on the left.
- **One-Click Debate**: Click "One-Click Debate" in the right chat panel. At this time, the backend will automatically grasp various financial and technical factors and organize three AIs to debate in turn.
- **Individual Chat**: Click the "🐂 Bull" or "🐻 Bear" avatar below to ask vertical questions related to specific financial indicators or recent events according to their specific stances.
